# 사용자 정의와 운영 설정

## 위젯 사용자 정의

- 로그인 위젯의 로고, 색상, 문구와 레이아웃을 서비스 브랜드에 맞추는 기능이다.
- 현재 계정에서는 Xsolla 제품 라이선스 계약 전이라 사용할 수 없었다.
- 표준 위젯으로 Google 로그인 동작을 먼저 확인했으므로 기능 학습에는 문제가 없다.

## 이메일 사용자 정의

- 이메일 인증, 비밀번호 재설정, 일회용 로그인 코드 등에 사용되는 이메일의 디자인과 문구를 바꾸는 기능이다.
- Google 소셜 로그인만 사용하는 현재 단계에서는 설정하지 않았다.

## SMS 사용자 정의

- SMS 인증 메시지의 내용을 서비스에 맞게 바꾸는 기능이다.
- 전화번호 또는 SMS 로그인을 사용하지 않으므로 설정하지 않았다.

## 통신 서비스 제공업체

- **이메일 서비스 제공업체**: Xsolla 기본값 유지
- **SMS 서비스 제공업체**: 설정하지 않음
- 향후 자체 SendGrid 또는 SMS 제공자를 사용할 명확한 운영 요구가 있을 때만 변경한다.

## 약관 및 정책

학습 단계에서는 비워두었다. 실제 서비스 출시 전에는 다음 공개 URL을 준비하여 등록해야 한다.

- 서비스 이용약관
- 개인정보처리방침
- 환불 및 결제 관련 정책
- 필요한 경우 쿠키 또는 마케팅 수신 정책

문서 URL은 사용자가 로그인 전에 읽을 수 있도록 공개 HTTPS 주소여야 한다.

## 나이 제한

- 게임에 접근할 수 있는 최소 연령을 지정하는 기능이다.
- 현재는 대상 국가, 게임 등급과 법적 요구사항이 정해지지 않아 설정하지 않았다.
- 운영 단계에서 지역별 개인정보 보호와 미성년자 결제 정책을 함께 검토한다.

## Apple 자체 로그인 보류

- 자체 Apple OAuth 구성을 위해서는 Apple Developer Program 가입과 Apple의 App ID, Services ID, Key 설정이 필요하다.
- 개인 학습을 위해 비용을 지불하지 않고 이번 범위에서는 제외했다.
- 회사 프로젝트에서는 회사의 Apple Developer Organization 팀이 계정과 키를 소유하고 담당 직원을 팀에 추가하는 방식이 적절하다.

## 운영 전 체크리스트

- [ ] Xsolla 제품 라이선스 계약 검토
- [ ] 브랜드 위젯 디자인 적용
- [ ] 이용약관 및 개인정보처리방침 등록
- [ ] 운영 HTTPS 도메인과 Callback 등록
- [ ] 개발용 localhost 설정과 운영 설정 분리
- [ ] Google OAuth 앱 게시 상태와 승인 범위 확인
- [ ] 비밀 키를 Secret Manager 또는 서버 환경변수로 관리
- [ ] JWT 검증과 로그아웃·만료 처리 구현
- [ ] 로그인 실패 모니터링과 고객지원 절차 준비
