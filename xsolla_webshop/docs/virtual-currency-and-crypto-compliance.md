# Xsolla 가상 화폐와 실제 가상자산 사업 구분

> 이 문서는 Xsolla 공식 문서와 대한민국 금융위원회 안내를 학습 목적으로 요약한 자료다. 실제 서비스 출시·토큰 발행·매매·중개 전에는 변호사와 금융 규제 전문가의 검토가 필요하다.

## 1. 결론

현재 이 프로젝트의 BLUC는 블록체인 기반 암호화폐가 아니라 웹숍과 게임 안에서 사용하는 게임용 가상 재화(virtual currency)로 설계한다.

Xsolla와 계약하면 가상 아이템, 가상 화폐, 번들을 판매하는 Web Shop을 구성할 수 있다. 그러나 Xsolla 계약만으로 실제 암호화폐의 거래소, 매매 중개, 원화 교환, 수탁 또는 토큰 발행 판매 권한이 생기는 것은 아니다.

## 2. Xsolla Web Shop에서 가능한 범위

Xsolla Web Shop은 Xsolla 인프라에서 동작하는 데스크톱·모바일 웹숍이다. 주요 기능은 다음과 같다.

- 스토어프런트 구성
- 가상 아이템, 가상 화폐, 번들 판매
- 프로모션, 보상, 구독, 개인화
- Pay Station을 통한 결제
- 로그인과 사용자 검증
- 결제 성공 웹훅
- 구매 상품을 게임 계정에 지급

### 일반적인 흐름

사용자 웹숍 접속
→ 로그인
→ Xsolla가 게임/백엔드에 사용자 검증 웹훅 전송
→ 사용자가 상품 선택
→ 결제 화면 표시
→ 결제 성공 웹훅 전송
→ 게임/백엔드가 상품 또는 가상 화폐 지급

### Xsolla Web Shop 기본 통합 순서

1. Xsolla 프로젝트 생성
2. Web Shop 구성
3. 아이템 카탈로그 생성 또는 API 연동
4. 사용자 인증 설정
5. 구매 상품 지급 처리 구현
6. 필요한 경우 구독 설정
7. 스토어 메인 블록 구성
8. Sandbox 환경에서 테스트
9. 사이트 게시
10. Live 환경 테스트

실제 결제를 받으려면 Xsolla License Agreement 체결과 심사가 필요하다. Xsolla 문서는 계약을 어느 단계에서든 체결할 수 있지만, 신청 검토에 영업일 기준 최대 3일이 걸릴 수 있다고 안내한다.

## 3. 게임용 가상 화폐와 암호화폐의 차이

### 게임용 가상 화폐

예: BLUC

- 게임 또는 웹숍 내부의 상품·서비스 이용 단위
- Xsolla 카탈로그에서 패키지로 판매 가능
- 서버가 잔액과 지급 내역을 관리
- 일반적으로 현금화하지 않음
- 다른 사용자에게 자유롭게 송금하거나 거래소에서 거래하지 않음
- 가격, 지급량, 환불, 만료 정책을 서비스 약관에 명시해야 함

### 실제 암호화폐 또는 가상자산

예: 외부 블록체인에서 전송·거래되는 토큰

- 블록체인 주소와 지갑을 사용
- 사용자 간 이전 가능
- 다른 가상자산 또는 법정화폐와 교환될 수 있음
- 매매·교환·이전·보관·관리·중개가 규제 대상이 될 수 있음
- 발행·판매 자체도 토큰 성격에 따라 별도 법률 검토가 필요함

## 4. Xsolla Wallet 가상 화폐 약관의 핵심

Xsolla Wallet 약관은 Xsolla 생태계의 Virtual Currency를 폐쇄형 서비스 안에서 사용하는 라이선스로 설명한다.

- 특정 프로젝트에 따라 가상 화폐의 이름은 달라질 수 있다.
- Xsolla 생태계 안에서 디지털 아이템·구독 등을 구매하는 데 사용할 수 있다.
- 가상 화폐는 금전적 가치가 없도록 운영될 수 있다.
- 현금, 다른 통화, 재산, 상품, 서비스 또는 경제적 이익과 교환할 수 없다.
- 다른 사용자나 지갑으로 양도·판매·거래할 수 없다.
- 사용자에게 소유권을 이전하는 것이 아니라 제한적이고 철회 가능한 사용 라이선스를 부여한다.
- 부정행위 또는 약관 위반이 의심되면 Xsolla가 잔액·지갑·접근 권한을 중지하거나 종료할 수 있다.

따라서 이 약관의 Virtual Currency와 외부 거래 가능한 암호화폐는 같은 개념으로 취급하면 안 된다.

## 5. 대한민국에서 실제 가상자산 매매·중개를 하려는 경우

금융위원회 안내에서 가상자산사업자 관련 행위로 다음을 설명한다.

- 가상자산의 매도·매수
- 다른 가상자산과의 교환
- 가상자산의 이전
- 가상자산의 보관 또는 관리
- 매도·매수·교환의 중개·알선·대행

국내에서 또는 내국인을 대상으로 영업하려면 특정금융정보법에 따른 가상자산사업자 신고 등 요건을 검토해야 한다. 금융위원회는 신고 없이 가상자산을 매매·교환해 주거나 중개·알선하는 행위를 불법행위로 안내한다.

검토 대상에는 다음이 포함될 수 있다.

- 금융정보분석원(FIU) 신고 대상 여부
- ISMS 인증 등 정보보호 요건
- 자금세탁방지(AML)와 고객확인(KYC)
- 이용자 자산 보호
- 실명확인 입출금 계정 등 금융 요건
- 개인정보 보호
- 전자금융·외국환·소비자보호 규정
- 토큰이 증권에 해당하는지 여부
- 한국인을 대상으로 하는 마케팅·한국어 사이트·원화 결제 여부

신고가 필요한 사업을 신고하지 않고 운영하면 형사처벌 및 행정 제재가 발생할 수 있다. 금융위원회는 미신고 불법 영업행위에 대해 5년 이하의 징역 또는 5천만 원 이하의 벌금 가능성을 안내하고 있다.

## 6. 이 프로젝트에 적용할 안전한 범위

사용자 결제
→ Xsolla Pay Station
→ Xsolla 결제·웹훅
→ 백엔드가 BLUC 지급
→ 게임 또는 웹숍에서 BLUC 사용

다음 기능은 현재 프로젝트 범위에 포함하지 않는다.

- BLUC를 외부 거래소에 상장
- BLUC를 원화로 환전
- 사용자 간 BLUC 송금·거래
- 다른 사람을 대신한 암호화폐 매매
- 암호화폐 거래 중개 또는 알선
- 실제 토큰 발행 및 투자자 대상 판매

## 7. 출시 전 체크리스트

- [ ] BLUC가 게임 내부 가상 재화인지 실제 가상자산인지 법률 검토
- [ ] Xsolla License Agreement 및 사업 심사 확인
- [ ] 상품·환불·가상 화폐 이용 약관 작성
- [ ] 결제 성공 웹훅 서명 검증
- [ ] 거래 ID 멱등성 처리
- [ ] 지급 원장과 중복 지급 방지
- [ ] 환불·차지백 시 재화 회수 정책
- [ ] 실제 가상자산 기능이 있다면 FIU 신고 대상 여부 확인
- [ ] 개인정보·AML·KYC·소비자보호 요건 검토
