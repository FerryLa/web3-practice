# 인증

이 카테고리는 Google 같은 기본 소셜 로그인 외의 인증 경로를 추가하는 영역이다. 현재 학습에서는 모두 기본 상태로 유지했다.

## 퍼블리싱 플랫폼

- Steam, Epic Games, 콘솔 플랫폼 또는 자체 런처가 발행한 인증 정보로 로그인할 때 사용한다.
- 현재 웹숍은 Google 계정을 사용하므로 연결하지 않았다.
- 장차 실제 게임 계정과 웹숍 계정을 동일하게 만들어야 할 때 다시 검토한다.

## OAuth 2.0 로그인 연결

- 목록에 없는 회사 자체 계정 시스템이나 사용자 정의 OAuth 제공자를 Xsolla에 연결하는 기능이다.
- Google Cloud에서 만든 Google OAuth Client와는 다른 설정이다.
- Google은 이미 **소셜 네트워크** 메뉴에서 연결했으므로 이곳에 중복 등록하지 않았다.

## 다양한 데이터 양식

- 가입 과정에서 닉네임, 생년월일, 국가 등 추가 정보를 수집하는 화면을 구성하는 기능이다.
- 현재는 Google의 기본 프로필과 이메일만으로 충분하므로 사용하지 않았다.
- 개인정보를 추가로 수집하면 목적, 동의, 보관 기간과 관련 법률을 함께 검토해야 한다.

## 현재 결론

```text
추가 데이터 양식: 사용 안 함
기본 인증 경로: Google Social Login
```
